# 抖音直播流提取器 (Douyin Live Extractor)

这是一个用于提取抖音直播间真实推流地址（FLV / HLS）的工具。项目不仅可以在本地通过 Node.js 命令行直接运行，还提供了一套完整的前后端 Web 交互界面，支持部署到 Cloudflare Pages 以实现边缘网络加速和零成本托管。

## 🌟 主要功能

1. **一键解析与提取**
   - 支持通过传入**抖音直播链接**、**房间号 (Room ID)**、**`v.douyin.com` 短链接**或 App 复制的**整段分享文本**快速解析；短链接会跟随跳转换算出房间号。
   - 解析成功后输入框、重新加载和历史记录统一使用房间号（旧版保存的直播间链接会自动转换）。
   - 自动获取直播间的主播昵称、标题、封面及开播状态。
   - 解析出各清晰度（如原画、超清、高清等）的推流播放地址（包含 FLV 和 HLS 格式）。

2. **Web 沉浸式播放器** *(仅限 Web 版/Cloudflare部署版)*
   - 内置基于 `flv.js` 和 `hls.js` 的网页端播放器，提取后可直接在网页内看直播。
   - **清晰度切换**：支持直播源多种画质选择。
   - **自动画质新鲜度对比**：解析房间后，在“画质对比 · 哪个画面更新”选择两种 FLV 画质，点击“开始自动对比”。两路先追帧并稳定播放（新连接开头会以高于实时的速度收到 CDN 缓存画面，追帧每秒最多一次，持续到缓冲不再积压；准备阶段最长 25 秒），再采样 20 秒，按解码后连续画面的相似特征估算显示时间差；无需人工观察，也不直接比较不同流的原始时间戳。默认包含标清以减少并发带宽压力。
     - 显示本次领先画质、相对落后秒数和估算容差，可点击“使用领先画质”切换。约 0.2 秒以内的差异视为近似同步，不强行推荐。结果仅针对所选两路、当前网络和设备条件，并非全部画质排名或摄像头到屏幕的绝对延迟。
     - 缓冲持续积压、静止或重复画面、匹配不连续、卡顿、延迟波动、跨域取图受限、不同画面比例或有效样本不足时显示“无法判定”。预计可比较不超过 8 秒的时间差，更大的差距也可能无法匹配；图像匹配是估算，不能保证识别所有歧义画面。
     - 使用新版 Chrome / Edge，保持页面在前台；目前沿用 H.264 FLV 播放支持。测试暂停主播放器以减少争用，结束或取消后恢复原播放/暂停状态；切换直播或退出会终止旧测试。不能和线路测速同时进行。并发播放仍会增加带宽与解码负担。
   - **播放控制**：支持无级变速（0.5x - 2.0x 倍速播放）、全屏模式。
   - **可选同步模式**：播放器下方可选择“平滑追赶”或“最新画面优先”（默认），并记住选择。每次 FLV 连接首帧可播时都会跳过 CDN 缓存的旧画面，追到缓冲末端。“平滑追赶”以加速为主，落后超过 1.5 秒才跳转；“最新画面优先”落后超过 1 秒即跳到已缓冲的最新画面，跳转后仍持续明显落后时才重新拉流。两种模式在连接出错或播放停滞时都会自动重新连接，可能短暂等待。两种模式均支持“自动同步”开关，关闭后只响应手动同步，也不自动重连。
   - **手动同步与重连**：“平滑追赶”模式的“同步直播”跳转到可用直播位置；“最新画面优先”模式的同一按钮立即重新连接。当前画面仍在正常播放时，新连接先在后台加载并追到最新画面，就绪后再替换，重连过程不黑屏；新连接出错或 10 秒内未就绪则保留当前画面，下次重连改为重新解析。已断流或停滞的连接直接替换。“同步直播”和自动重连会复用仍有效的播放地址（按地址中的 `expire` 判断，距到期不足 1 分钟才更新）；连接出错或点击“重新加载”时会重新解析房间，并优先保留当前画质；直链会重新打开原地址。自动重连至少间隔 15 秒，连续最多 3 次；连续正常播放 30 秒后恢复重试预算。HLS 优先使用播放器提供的直播同步位置；实际画面新鲜度仍受源站与网络影响。
   - **线路测速与选择**：解析后在“线路测速 · 选择最新画面”中选择测试画质，再点击“开始测速”。浏览器跟随真实播放跳转发现线路，最多比较 5 条；数量取决于平台调度，也可粘贴同直播、同画质的备用 FLV 地址。平台按请求方 IP 分配 CDN，部分 CDN（如腾讯系域名）每次跳转到同一地址，只能发现 1 条；后端每次解析会同时查询直播页和房间信息接口，不同 CDN 的地址自动作为候选，同一房间多次解析或重连得到的未过期地址也会累积进测速候选。默认标清以减少并发带宽压力，使用结果会切换到测试画质。
     - 测速会停止当前拉流，完成或取消后恢复原播放状态；切换直播、退出登录或离开页面会中止旧测试。
     - 每条线路使用同一条网络连接同时供给实际 FLV 试播播放器和时间戳观测，不额外拉一份视频。首帧就绪后跳到缓冲末端前约 0.35 秒，再检查播放和数据时间推进。首帧加载耗时单独展示，不参与新鲜度排名；发现阶段 15 秒超时的地址仍保留为待确认候选，试播加载可等待 20 秒。
     - 连接或追帧失败、以及完成追帧后仍比已对齐线路落后超过 1 秒时，给予一次重连再追帧的机会。准备过程最多 100 秒，每次连接最多追帧 3 次。通过后继续使用处理后的连接采样 12 秒。界面显示每条线路的首帧加载耗时、追帧次数和重连次数。
     - 使用历史同帧指纹核对共同时间轴，允许跨阶段、跨时段对齐，避免把领先过多而未在短窗口内重叠的节点误判为旧画面。仍未对齐或未完成加载/追帧的候选显示“未判定”，此时不推荐全部候选中的最新线路。
     - 表格区分“同帧到达差”（处理后窗口内共同画面的到达中位差）和“处理后画面落后”（结束时收到的最新可用帧进度差）。共同时间轴已确认但窗口没有足够重叠时，同帧差可以留空，仍可比较画面进度；加载耗时不参与排名。小于 1 ms 视为近似并列。试播先确认已追到缓冲末端，但原始 FLV 时间戳没有直接映射为浏览器实际显示时间，因此不宣称摄像头到屏幕的绝对延迟或源头全局最新帧。
     - 点击“使用最新线路”或某行“使用”即可播放该线路，新连接首次可播时会自动追帧。同步重连会保留选择；所选线路报错时，房间链接会重新解析并回到平台提供的线路。
     - 目前支持 H.264 FLV 的同帧比较，需 HTTPS 或 localhost 页面、浏览器允许跨域读取，并保持页面在前台。HLS/H.265、不同画质、签名过期、跨域受限、预热未完成或不足两条不同线路会显示原因，不生成虚假的测速结论。浏览器不能绕过 HTTPS 页面对 HTTP 地址的限制。

3. **双重运行模式**
   - **本地脚本命令行模式**：通过简单的 Node.js 端脚本，实现开箱即用的控制台直接打印真实地址，并对部分 URL 提供通用验证与提取。
   - **Serverless 边缘无服务器模式**：前端采用现代风格的响应式中文 UI，后端使用 Cloudflare Pages Functions，彻底免除跨域问题，并在全球范围内提供极其迅速的 API 调度方案。

4. **安全鉴权**
   - Web 部署版内置基于 JWT 的轻便安全鉴权框架，采用前端用户名与密码匹配环境变量存储 Secrets 的鉴权流程，防止公网部署后未授权用户滥用。
   - 可通过全局配置 `requireLogin` 控制是否需要登录，默认开启。

## 🚀 本地运行 (命令行模式)

如果您只需要本地解析且无需图形界面，您可直接使用根目录下提供的环境进行简单调用：

1. **安装主要依赖**：
   ```bash
   npm install
   ```

2. **基本用法**：
   ```bash
   node index.js <直播间链接 或 房间号>
   ```

3. **示例**：
   ```bash
   node index.js https://live.douyin.com/1234567890
   # 或者直接使用房间号
   node index.js 1234567890
   ```
> **注意**：由于抖音存在反爬虫机制。如果发现在本地运行时显示“失败”或者卡住拿不到任何有效返回流，可能需要通过浏览器 DevTools 抓取有效的 `__ac_nonce` 、Cookie 或者其他必要的 Headers 参数放入到 `index.js` 发送请求的方法中。 

## ☁️ 部署到 Web (Cloudflare Pages版)

如果您想要使用带有图形界面、流播放器和账号登录模块的完整应用，我们强烈建议将其部署到 Cloudflare Pages 环境中。

在所有的前端资产及 `Functions API` 我们放在了 `Cloudflare` 文件夹中。您可以实现零成本、免服务器的页面与后端接口整体托管。

关于详细部署方式（比如链接 Git，使用 Wrangler），以及必须的环境变量配置，请参考该特定子包的部署文档：[Cloudflare 部署指南](./Cloudflare/README.md)

## 🔐 登录开关

本地 Web 服务读取根目录 `config.json` 中的 `requireLogin`：

```json
{
  "username": "admin",
  "password": "password123",
  "requireLogin": true
}
```

将 `requireLogin` 改为 `false` 后，页面会直接进入主界面，`/api/live` 也不再校验 token。
